How it all works.

Wormhole gives every model you configure a single OpenAI-compatible endpoint. Keys live in .env, routing lives in config.yaml, usage lives here.

Quick start

1. Add providers to config.yaml · 2. Put their API keys in .env · 3. Restart. The demo model works with zero setup.

# .env — real provider keys, never committed GROQ_API_KEY=gsk_your_key_here OPENROUTER_API_KEY=sk_or_your_key_here
# config.yaml providers: - name: groq # known provider, base URL built in key_env: GROQ_API_KEY models: - id: llama-3.3-70b # the name you call it by provider: groq upstream: llama-3.3-70b-versatile # the provider's real name tags: [free, fast]

The wh CLI helper

A tiny command-line client for any Wormhole server — local or shared. Build it with go build -o wh.exe ./cmd/wh.

wh models # list models wh chat "Explain routers" # chat (streams, keyless) wh chat "Hi" -model kilo/nemotron-3-nano # pick a model wh chat "Hi" -key sk-wormhole-... # use your own key wh keys create my-app # create a key (local server) wh usage # 7-day totals # point at a shared server instead of localhost: set WH_SERVER=https://your-server.vercel.app wh chat "Hello from afar"

Call it from anywhere

curl http://localhost:8080/v1/chat/completions \ -H "Content-Type: application/json" \ -d '{ "model": "pollinations/openai-fast", "messages": [{"role": "user", "content": "Hello!"}], "stream": true }' # keyless models need no Authorization header from localhost; # from elsewhere add: -H "Authorization: Bearer sk-wormhole-..."
# Python — works with the standard OpenAI client from openai import OpenAI client = OpenAI(base_url="http://localhost:8080/v1", api_key="sk-wormhole-...") resp = client.chat.completions.create( model="pollinations/openai-fast", messages=[{"role": "user", "content": "Hello!"}], ) print(resp.choices[0].message.content)

API reference

GET /v1/modelsList all configured models with pricing and context. No auth needed.
POST /v1/chat/completionsOpenAI-compatible chat completions. Supports streaming. Requires a key created on this site (local requests are exempt).
GET /healthLiveness check.
GET /api/overviewDashboard stats. Localhost only.

Free providers — one free signup

Grab a free key from any of these, put it in .env, and you have a free AI API. Easiest start: copy config.free.yaml config.yaml — it ships with all of them preconfigured.

Provider presets

Use one of these names and the base URL is filled in automatically. Any other OpenAI-compatible provider works too — just set base_url manually.

Config reference

server.portPort to listen on (default 8080, localhost only).
server.nameDisplay name used across the dashboard and demo model.
providers[].namePreset name or your own label.
providers[].base_urlOverrides the preset URL.
providers[].key_envName of the environment variable holding the API key. Omit for keyless local providers.
models[].idPublic name your apps request.
models[].upstreamActual model name at the provider (defaults to id).
models[].price_in / price_outUSD per 1M tokens. Both zero = free (shown as Free).
models[].tagsfree, paid, fast, local, reasoning — used by dashboard filters.
limits.default_key_monthly_limitPre-filled monthly spend cap for new keys (USD).
